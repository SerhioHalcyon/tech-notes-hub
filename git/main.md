# Conventional Commit types:

feat — new functionality

fix — bug fix

docs — documentation only

style — code style/formatting changes (no logic): spaces, commas, linting

refactor — code refactoring without behavior changes

perf — performance improvements

test — adding or updating tests

build — build system, dependencies, or package manager changes

ci — CI/CD configuration, scripts, or pipelines

chore — other routine tasks not affecting application code (routing, metadata, config updates)

revert — revert a previous commit
